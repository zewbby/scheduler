# 冲冲冲

## 作用

个人日程本。支持离线保存、Cloudflare 同步、搜索和备份，当前保留单账号使用。

## 技术栈

React、TypeScript、Vite、Electron、Capacitor、SVG。

## 安装包

[下载 Windows 64 位安装包 · v0.6.0](https://github.com/zewbby/scheduler/releases/download/v0.6.0/ChongChongChong-Setup-0.6.0.exe) · [版本记录](https://github.com/zewbby/scheduler/releases)

安装时可分别选择软件目录和日程数据目录；升级默认保留原数据。也可在设置「存储」页查看、更换数据位置。

Android 首版为 **0.7.0 预览版**。可在 [Android 构建](https://github.com/zewbby/scheduler/actions/workflows/android.yml) 下载成功运行生成的 APK 产物，解压后安装；也可运行 `pnpm android:debug` 本地生成。预览 APK 使用调试签名，安装、构建和正式签名说明见 [Android 文档](docs/android.md)。

## 适用系统

Windows 10 / 11，64 位；Android 7.0 及以上，要求 Android System WebView / Chrome 108 或以上。Android 已提供独立安装工程与手机布局；macOS 版本尚未发布。
