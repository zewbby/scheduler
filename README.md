# 冲冲冲

## 作用

卡片式日程本。按月查看每天的卡片，点击日期展开当天待办，勾选完成后文字变淡并显示删除线。支持离线保存、Cloudflare 同步、搜索和备份。

## 技术栈

React、TypeScript、Vite、Electron、SVG、Cloudflare Workers、D1。

## 安装包

[Windows 安装包与版本记录](https://github.com/zewbby/scheduler/releases)。本次 0.3.0 安装包将在修改和验证完成后附到 Release。

## 适用系统

Windows 10 / 11，64 位。当前在 Windows 11 验证。macOS、Android 版本尚未发布。
