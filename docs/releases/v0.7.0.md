# 冲冲冲 v0.7.0

日期：2026-10-15。Android 第一版，与 Windows 版共享界面、账号和日程数据模型。

## Android

- 新增 Capacitor 8.5.3 Android 工程，应用标识 `app.liubai.planner`，版本 0.7.0、`versionCode` 7，最低 Android 7.0（API 24），目标 API 36。
- 沿用草地插画登录页和日程卡片，适配手机窄屏与触屏操作；待办增加明确的编辑和删除入口。
- 支持新增、完成、改名、删除、待办时间、搜索、头像，以及中英文、浅色／深色和点缀色设置。
- Android Keystore 加密保存离线账号校验记录与同步凭据，首次联网登录后可离线使用；返回前台或恢复联网时重试同步。
- 通过系统文件界面导出 JSON 备份，并支持导入合并；Android 存储设置使用设备对应的说明。

## 同步与兼容

继续使用已有 Cloudflare Worker 与 D1 工作区。相同账号的 Windows 和 Android 设备可同步日程与头像，本次不修改日程数据结构。线上同步接口已通过 Android 所用 `https://localhost` 来源的预检验证。

Android 日程存储位于应用私有目录。卸载或清除应用数据会删除本机数据；请提前同步或导出尚未同步的记录。迁移到新设备后重新登录，通过云端或 JSON 备份恢复日程。

## 开发与自动检查

新增 Android 同步、打开工程、调试构建及 Release 构建命令，并增加 GitHub Actions：固定 Node.js 24、pnpm 11.25.0、JDK 21 和 SDK 36，执行单元测试、生产构建、浏览器回归、Android 调试 APK 构建和 lint，保存调试 APK、校验文件及检查报告。

完整开发、构建和检查步骤见 [Android 说明](../android.md)。

## 分发与验证边界

当前自动构建产物是调试签名的预览 APK。不同构建环境的调试签名可能不同；正式长期升级需要在 Android Studio 配置并妥善保存同一套私密签名密钥。本次没有配置 Google Play 发布或提交正式签名密钥。

本机验证：34 项单元与接口测试通过；完整浏览器回归 20 项通过，1 项真实账号测试因未提供私密凭据跳过。Android 调试 APK 构建和 lint 通过（0 错误）；Android 16 模拟器上 2 项 Keystore 仪器测试通过，并验证原生桥、后台后杀进程再离线登录、待办保留、软键盘、系统返回键及系统备份保存与取消。

尚未在实体手机验证；真实账号跨 Windows／Android 同步、设备厂商键盘、文件提供方和正式签名覆盖升级仍需真机检查。模拟器冒烟使用临时测试账号并拦截云端请求，双设备同步协议由接口与浏览器测试覆盖。
