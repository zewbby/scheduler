# 冲冲冲 v0.6.0

发布日期：2026-10-14。此版本汇总 v0.5.0 发布后的全部界面调整。

## 登录页面

- 登录页改为全屏双熊、日程本与草地插画，移除原品牌文字、宣传文案、笔记本叠图和右上装饰图标。
- 顶部居中显示「Why Not Do It」；无外框的登录区位于双熊和日程本之间，轻透输入与草绿底线自然融合背景，深棕文字和暖黄按钮保留对比度。
- 插画随应用本地打包，完整显示角色和日程本，并适应桌面窗口及窄屏布局。

## 月视图与顶栏

- 简化顶栏头像，展示账号 ID。
- 弱化「本月」按钮的视觉重量，调整刷新图标。
- 调整月份标题的字体、字重、对齐和间距。

## 纳入的历史提交

从 v0.5.0 到本次登录插画更新之前，共纳入以下 5 个提交：

- `85ee586`：更新登录标语。
